台灣十六張麻將 TaiwanMahjong 1.1.2
適用：Paper 26.3 / Java 25。全繁中，無外部插件依賴。

牌面：42 種傳統萬筒索、字牌與花牌圖片，整合在進服自動下載的資源包。
桌面與選單都用圖片；中文牌名保留於滑鼠提示與聊天紀錄。

開始玩
1. /mj list 查看牌桌；/mj tp 牌桌一 前往出生點附近的預設桌。
2. 右鍵桌邊「空位」入座；/mj 可重新打開操作選單。
3. 真人先一起入座，再用 /mj practice（或 /mj bots）免費開局，空位自動補電腦。
   1～3 位真人都能一起玩；四位真人也可選免費練習。免費場不存款、不扣款、不發鑽石。
4. 鑽石對局要四位真人；每人先 /mj deposit 5 存入 5 顆原版鑽石，然後點「準備」。
   所有人準備後才保管押金；這不是入場費。未輸掉的押金全部退回個人帳戶。
   每人單局最多扣掉當局押金，不會另扣背包或帳戶餘額；超額應付款會觸發天空還債挑戰。
5. /mj balance 查可領餘額，/mj withdraw 數量 領回原版鑽石。
   有自訂名稱、附魔、Lore 或其他自訂資料的鑽石／寶石不收。

操作
- 輪到自己時，/mj 選單點「摸牌」，再點手牌出牌。莊家起手十七張，先出牌。
- 摸牌、出牌及合法吃碰槓胡選項，會顯示於選單、牌桌、畫面下方及聊天欄。
- 剛摸到哪張牌只告訴本人；補花、槓後補牌自動完成。吃、碰後直接出牌，不多摸一張。
- 右鍵自己的立體麻將牌可直接出牌。牌太小不好點時，右鍵座位開選單，點牌出牌。
- 吃、碰、明槓、暗槓、加槓、胡牌／榮和、自摸，在合法時顯示按鈕。
- 吃只能吃上家；胡牌優先於碰槓，碰槓優先於吃；允許一炮多響。
- 自己的未公開手牌只傳送給自己，其他玩家與觀眾只能看到牌背。
- 選單有聽牌及「打掉這張後聽什麼」提示。
- 台灣十六張不採用日式立直、七對子、國士無雙；不能把十四張牌型混入十六張。
- /mj help 開啟繁中規則書，列出本桌全部計分台型。

結算
每筆 = 底 5 顆 + 2 顆 × 台數。例：結算總台數為 3 台時，該筆為 11 顆。
放槍由放槍者付；自摸由其餘三家各付。多人胡牌分別支付，不抽水。
每位付款人單局總付款最多為開局時保管的押金（預設 5 顆）。
一炮多響若總額超過押金，依各得獎者原應收金額比例分配；不足整顆的餘數由大到小補齊，
餘數相同依原結算順序。結算會顯示實付金額及封頂前應付金額，鑽石總量不變。
例如同一人原應付兩家各 21 顆，押金 5 顆時按原結算順序實付 3 顆及 2 顆。
升級前已開始的牌局仍使用該局原本保管的押金額度，不受新預設 5 顆影響。
升級前的牌局保留自動摸牌，並且不追溯競技場欠債；新開局才採用手動摸牌及下列挑戰規則。
付款者或胡牌者是莊家時，該筆另加 1 + 2×連莊次數 台。
遊戲程式逐筆列出台型、台數、付給誰及鑽石數量。
流局退回所有押金並連莊；莊家胡牌連莊，其他人胡牌換莊。
一般五面子一對將：零台也可以胡牌。
七搶一、八仙過海屬花牌特殊胡法，不要求一般五面子一對將。

天空還債挑戰
- 新鑽石局結算時，每人的應付總額超過押金，差額記為欠債；免費局不觸發。
- 例如原應付 42、押金 5：實扣 5，另外 37 記為挑戰欠債。胡牌方只分配實際押金。
- 欠債者會被傳送進 20×20 高空擂台，對戰十隻伏守者。多位欠債者依序挑戰。
- 擊敗全部十隻：清債，獎勵 64 顆鑽石存入麻將錢包，/mj withdraw 64 領取。
- 戰鬥中死亡：清債，保留裝備、背包與經驗，不產生墓碑；正常區域死亡規則不變。
- 不會補滿生命或代換裝備。離線／重啟會暫停，已擊敗數保留，重新登入繼續。
- 挑戰期間不能傳送逃離、改模式或蓋方塊。競技場伏守者不掉額外物品或供反覆刷經驗。
- /mj arena watch：傳送到安全觀戰席；/mj arena leave：返回觀戰前位置。
- /mj arena status：查看欠款及擊敗數。/mj 選單也有觀戰入口。
- 觀眾不能傷害、治療或干預挑戰。戰鬥與觀戰結束後恢復原本模式、飛行設定與位置。
- 場地在首次載入新版時，於主世界出生點附近的高空空白範圍建造；不覆蓋既有建築。

本桌計台（各地台麻規則不同，以下為此插件採用的固定預設）
門清 1、自摸 1、門清自摸合計 3。
平胡 2：全順子、無字無花、雙頭聽、非自摸。
碰碰胡 4、混一色 4、清一色 8、字一色 16。
三暗刻 2、四暗刻 5、五暗刻 8，只取最高；四槓胡 8。
中發白刻各 1，門風與圈風刻各 1。
小三元 4、大三元 8，成立時不另計三元刻。
小四喜 8、大四喜 16，成立時不另計門風與圈風刻。
正花各 1、春夏秋冬或梅蘭竹菊一組花槓各 2。
獨聽 1；全求人 2，不另疊獨聽。
天胡 16、地胡 16、人胡 8，不重複計門清、自摸、一摸三。
天胡為莊家起手胡；地胡為閒家第一次摸牌即自摸、未出牌、全桌未吃碰槓。
人胡為閒家胡莊家的開局第一張棄牌、全桌未吃碰槓。
七搶一 8：持七花者向持最後一花者收取；八仙過海 8：三家各付。
搶槓 1、槓上／補花自摸 1、海底撈月／河底胡 1。
放過能胡的棄牌後，自己下一次摸牌前不能榮和，仍可自摸。
使用 144 張含花牌，留 16 張牌尾；摸到最後活牌為花時可補花。
所有合法五面子一對將的拆法皆枚舉，取本桌規則下最高合法台數。

逾時、離線、重啟
摸牌與出牌各 45 秒、吃碰胡回應 12 秒。摸牌逾時自動摸；出牌逾時能胡就自動胡，否則摸打。
正式對局中離線不退款、不取消，繼續自動打牌；結算後餘額留在帳戶。
免費練習可以 /mj leave 隨時離開或離線，由電腦接替；其餘真人可繼續玩。
最後一位真人離開後清空練習局。不影響正式桌的莊位、連莊或鑽石。
正式對局每步都保存，重啟後從最近已保存的狀態繼續。
存提款會驗證玩家實際存檔中的交易收據；無法確認時拒絕繼續並提示重新登入。
伺服器磁碟故障或人工修改玩家資料／帳本不在正常復原保證範圍。

管理員
/mj create 牌桌名稱：站在 5×5 平坦空地中央，建立占地 3×3 的立體展示桌。
桌子由展示實體構成，不覆蓋／破壞原有方塊。兩桌至少相隔 7 格。
/mj remove 牌桌名稱：移除沒有進行中牌局的桌子，不刪個人帳戶。
預設最多兩張桌，避免大量展示實體影響伺服器效能。
taiwanmahjong.play 預設所有玩家可用；taiwanmahjong.admin 預設 OP。
無 VIP 要求，不會授予其他管理權限。
