It is distributed under the [SIL Open Font License 1.1](OFL.txt).

Downloaded from the official Noto repository:

- [Font](https://github.com/notofonts/noto-cjk/blob/main/Sans/OTF/TraditionalChinese/NotoSansCJKtc-Regular.otf)
- [License](https://github.com/notofonts/noto-cjk/blob/main/Sans/LICENSE)

Font SHA256: `dce08bd4fd91aa8aa76ed8fea4b694c2dfb8550f67871e326843212ddbeb88b4`

This complete font is retained to make builds independent of installed fonts.
It is used only during rendering; the Minecraft resource pack contains PNG
artwork and does not contain the font software.
